# 🚗 C++ Lane Detection (白線検知)

## 📌 何をするプロジェクトか
車載カメラの画像から、C++とOpenCV(Canny/Hough変換)を用いて道路の白線を検知・抽出するプロトタイプです。

## 🛠 使用技術
* C++20
* OpenCV 4.x
* CMake

## 🚀 ビルド方法
```bash
mkdir build
cd build
cmake ..
make
./LaneDetection
```

## 🔍 処理の流れ
1. 画像をグレースケール化
2. ガウシアンブラーでノイズを除去
3. Cannyエッジ検出でエッジを抽出
4. Hough変換で直線(白線候補)を検出
5. 検出した直線を元画像に重ねて描画・保存

## 💡 このプロジェクトの位置づけ

このプロジェクトは、白線検知としての完成度よりも、次のプロジェクトにつながった出発点として重要です。

開発の中で、CannyやHough変換のパラメータ(しきい値・線分長など)によって検出結果が大きく変わる一方、
パラメータ同士が絡み合っていて手作業での調整が非効率だと感じました。

この課題意識から、パラメータの許容範囲を探索・可視化するツール [SBPE](https://github.com/mailryogot85-ops/sbpe-terminal) を別プロジェクトとして構想・実装しました。

## 🔭 現状の課題
* 静止画像のみが対象で、動画・リアルタイム入力には未対応
* パラメータ調整は依然として手作業(この課題への取り組みが [SBPE](https://github.com/mailryogot85-ops/sbpe-terminal))
